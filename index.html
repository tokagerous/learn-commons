How each program works

  • Each program is a small set of HTML pages — no install, no signup, no tracking.
  • Click any unit on the left sidebar to jump in. Each unit has plain-language explanations, visual diagrams, hands-on interactives (drag-drop, sliders, calculators), and 15+ "Check your understanding" questions with try-again and per-distractor explanations.
  • Section tests run a CMA-pace timer (1.8 min/question), let you flag questions, and offer "Replay missed only" or "Replay flagged only" after grading.
  • Highlight any text to mark it (4 colours), attach notes, and bookmark units. All saved per-browser, per-program.
  • Press / to search content, F for the formula reference, ? for keyboard help.
Open-source, no tracking, no signup. Progress and annotations live in each browser's localStorage, scoped per program. Switch devices and you'll start fresh on that device. Run locally by cloning the repo and opening index.html, or visit the deployed site.
